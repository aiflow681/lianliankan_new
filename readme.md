[游戏名称]连连看：浮岛冒险

[游戏介绍]
一个清新、可爱的 **HTML5 网页版连连看** 小游戏，主题为“浮岛冒险”。  
轻触或点击相同图案的方块（最多两个转弯），消除它们，挑战在限定时间内通关！

## 游戏特色

- 🎨 **浮岛清新画风**：柔和渐变背景 + 漂浮云朵动画
- 🧩 **经典连连看玩法**：支持最多 **两个拐弯** 的路径匹配（BFS 实现）
- ⏱️ **限时挑战**：120 秒倒计时 + 剩余时间奖励分数
- ⭐ **个人最佳记录**：使用 localStorage 保存最高分
- 📱 **响应式适配**：手机、平板、电脑都能流畅玩
- ✨ **消除动画**：路径高亮线 + 方块渐隐
- 🏆 **通关奖励**：剩余时间 × 50 分额外加成

[玩法说明]

1. 点击（或触屏）两个 **相同图案** 的方块
2. 如果它们之间可以用 **不超过两个转弯** 的直线连接（水平/垂直），即可消除
3. 尽量在 **2分钟** 内消除所有方块
4. 得分 = 每对 100 分 + 剩余时间 × 50 分
5. 点左上角返回键可随时回到菜单

[技术介绍]

- **HTML5 + CSS3**（响应式布局、渐变背景、backdrop-filter 毛玻璃）
- **纯 JavaScript**（无任何框架，极致轻量）
- **Canvas** 用于绘制消除路径动画
- **BFS 寻路算法**（判断是否可连，支持最多 2 次转弯）
- **localStorage** 保存最高分
- SVG 内嵌图标（12 种随机图案）
